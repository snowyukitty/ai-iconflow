# The collision set

Deliberately plain paths for the forms every operating system already owns.
`docs/LEARNINGS.md` L9 tells a designer to name what a silhouette already means
— circle+tail is search, gear is settings, house is home, bell is notifications,
triangle is play, and `+ ✓ ← # π` and a handful of letterforms are *text*. This
directory is that list, drawn, so the toolkit can run the test instead of
asking a person to squint.

Every file is a black path on the 1024 grid inside the safe area, with a
`<title>` naming the form. They are generic on purpose: no house style, no
optical corrections, nothing that would make a match say anything about a
particular product's icon set. A match says "at 16px this reads as a bell",
which is the finding, not "this looks like someone's bell".

Drawing them here rather than typing a glyph also removes the font problem
`iconflow/qa.py` names: a live `<text>` renders through whichever fonts the
build machine has, and a fingerprint of it would differ from machine to
machine. A path renders the same everywhere.

`index.json` beside them is generated by `scripts/build_collision_index.py`
and holds the 16px fields of these forms *and* of IconFlow's own published
marks. Never hand-edit it; rebuild it. `tests/test_neighbours.py` fails when
any entry's source has changed underneath it.

Adding a form: draw it, give it a `<title>`, rebuild the index, and add a line
to the table in `docs/NEIGHBOURHOOD.md`. Do not add anyone's actual icon.
