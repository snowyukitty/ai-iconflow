# IconFlow promotional film

Status: the revised 15-second hybrid production checkpoint passes automated
HyperFrames QA; human cinema preview and final render are still pending. The
30- and 60-second cuts remain machine-readable handoffs.

The production handoff lives in [`docs/promo/`](promo/): independent 60-, 30-,
and 15-second storyboards that follow Snowy HyperFrames' actual schema and
block-density limits. Their media bindings pin every copied visual to an exact
repository SHA-256.

## Concept

**The proof is the pixel.** Begin with the familiar false finish—an icon that
looks polished while large—then remove every place where a weak decision can
hide: color, scale, target chrome, and a stale approval. The film ends only when
one editable master has survived native 16px inspection and becomes the exact
favicon, PWA, desktop, and tray files it was reviewed to produce.

The audience tension is practical: generators make options and converters make
files, but neither owns the visible, repeatable design decision between them.
IconFlow is that local proof gate.

Lock the closing line:

> **One master. Every surface. Proven at 16px.**

## Evidence capture contract

Every frame must be real output. Use the packaged demo in a clean temporary
directory, the actual Review Lab, the exact archive scrubber, native PNGs, and
the real `ship` refusal. Motion graphics may compose and transition those
artifacts; they may not manufacture terminal output, UI, pixels, receipt
values, or success states.

The stale-receipt turn is the film. Capture a passing `ship`, move one real
control point in the same `master.svg`, rerun the same command in the same
terminal geometry, and hold on the refusal. If timing runs long, cut another
beat before shortening this one. Before the capture, clear scrollback and
confirm that no personal path, credential, or private repository name can enter
the frame.

Snowy HyperFrames is the production tool because its one-timing-truth pipeline,
strict check, offline review kit, and human preview gate match IconFlow's own
quality contract. A generative video model can be considered later for an
environmental plate or localized experiment, but not for hero-film evidence.
Any exact icon, word, interface, receipt, or output stays a deterministic
HyperFrames layer over or after that plate.

## 15-second production checkpoint — 2026-08-27

The first working cut now exists as a private Snowy HyperFrames production
project. Its opening uses an accepted Google Flow Quality plate of an empty
physical inspection frame, then overlays the exact checked-in IconFlow icon as
a deterministic 2× pixel layer. The real Review Lab proof sheet and checked-in
social-preview art carry the proof and ship beats. Generated motion never
represents product UI, review evidence, receipts, labels, or outputs.

The current checkpoint has:

- three source / proof / ship scenes across exactly 15 seconds;
- `0` HyperFrames audit errors and `0` warnings;
- `0` lint, runtime, layout, and motion findings;
- `21/21` text samples passing WCAG AA contrast; and
- a self-contained three-frame review artifact for the required human cinema
  preview.

This is deliberately **ready to preview**, not rendered or published. The
human gate still owns pacing, readability, sound, pixel fidelity, and final
permission to render.

Google Flow was used only for the physical opening plate. A Lite proof
established motion control, a Fast proof improved material quality, and one
Quality take won because it kept the frame rigid, stopped cleanly, preserved a
central overlay area, and visibly established multiple destination plinths.
Only the deterministic composite poster is staged under
[`assets/promo/`](assets/promo/). Generated motion is not accepted as proof and
cannot replace any real IconFlow output in the film.

A matching Grok Imagine Video 1.5 direction remains a local CineChorus dry-run,
not a retained campaign asset: it did not provide evidence that justified a
second paid branch after the Flow Quality take passed the visual gate.

## Production contract

- Master: 3840×2160, 24 fps, Rec. 709, 60.0 seconds.
- Keep every essential word, proof pixel, receipt field, output, and CTA inside
  the central 1216×2160 region (`x=1312–2528`). The 16:9 wings may continue the
  graphite grid or master rail, but carry no meaning.
  The mathematically exact 9:16 width is 1215px; 1216px is the deliberate
  even-pixel working width around that center.
- Use Graphite `#191A20`, Warm Paper `#FFF4E8`, and Signal Coral `#FF5A4F`.
  Keep the existing Lagoon, Gold, and Violet only inside approved assets.
- Use system grotesk for copy and tabular mono for measurements, hashes, file
  names, and commands.
- Use only `rise`, `hold`, `focus`, and `reveal` motion. Each shot chooses one.
- Composite approved icon pixels, Review Lab views, receipts, and outputs from
  the exact files below. Never regenerate, smooth, sharpen, redraw, or beautify
  them. Integer-scale the 16px PNG with nearest-neighbour sampling.
- Do not show mobile app-icon sets, Apple Icon Composer, fake OS chrome, generic
  AI gradients, sparkles, 3D blobs, or invented dashboards.
- `data/storyboard.json` plus measured audio is timing truth. Generated
  timelines, captions, and HTML are never hand-edited.
- Rendering stays blocked until a person passes the HyperFrames review kit for
  pacing, readability, sound, and pixel fidelity.

## Sound

Version one must work with no narration and no licensed music. Use a dry,
low-register pulse, one hard tick when the 16px grid appears, a stop-like stamp
when the receipt becomes stale, and four restrained ticks as the four target
files join the rail. Avoid stock whooshes, success chimes, sparkle grains, and
cinematic risers.

Narration is optional and intentionally sparse. Measure the actual clips and let
them set the timeline. If a line does not fit, shorten the line; never stretch a
slide or patch generated timing. A music bed remains deferred until its rights
and mix are reviewed. Silence is an acceptable bed for the final command.

## Cutdowns

Create these as separate storyboards with independently measured audio. Do not
trim generated HTML or inherit the 60-second timeline.

### 30 seconds

1. `0–3s` — `LOOKS DONE` (`hold`, master SVG rendered large).
2. `3–6s` — `PROVE IT AT 16` (`focus`, exact 16px proof).
3. `6–11s` — locked position line (`rise`, master SVG).
4. `11–16s` — native inspection (`hold`, review sheet).
5. `16–21s` — stale receipt blocks ship (`hold`, real receipt fields).
6. `21–26s` — four exact outputs (`rise`).
7. `26–30s` — `pip install iconflow` (`reveal`, no narration).

Use this cut when auditability matters; it retains the stale-receipt proof.

### 15 seconds

1. `0–4s` — `ONE SVG ENTERS` (`focus`): the physical frame moves, stops,
   then the exact IconFlow icon appears inside it.
2. `4–10s` — `PROVE IT AT 16PX` (`reveal`): the real Review Lab proof sheet,
   native pixels, target previews, and bound receipt.
3. `10–15s` — `SHIP EVERY SURFACE` (`focus`): the checked-in output family,
   `pip install iconflow`, and the locked proof-before-ship promise.

This is the reach hook: one source, visible proof, every surface. It explains
the product before asking the audience to learn the receipt contract.

## HyperFrames production handoff

1. Create a new private production project from the shared HyperFrames template.
2. Bind the exact assets above to slide-specific copies and record their hashes.
3. Copy one file from `docs/promo/storyboard-*.json` to
   `data/storyboard.json`; keep `production.status` and the project status at
   `draft`.
4. Run `hf html`, then the narration pipeline if narration is selected.
5. Run `npm run check` (`hf audit` plus the pinned strict browser gate).
6. Build `npm run review`; inspect the central 9:16 crop, nearest-neighbour
   pixels, reading time, pronunciation, and every cut.
7. Only a human may mark the preview passed. Render afterward, never before.
8. Keep MP4 renders out of Git; publish or deploy only through a separately
   approved release workflow.

The three release cuts must each pass their own timing, caption, strict browser,
and human review gates.
