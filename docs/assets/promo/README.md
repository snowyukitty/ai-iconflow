# Promotional motion sources

This directory contains the two highest-quality sources retained from the
Coral Gate motion study. They are campaign material, not product evidence.

| File | Role | Dimensions | SHA-256 |
|---|---|---:|---|

| `coral-gate-first-frame.png` | Exact raster render used by HyperFrames | 1920×1080 | `9d128a865729a81c9455dff1844e12c597b0d250dd998a8024c88b4e89ff0ecd` |
| `coral-gate-flow-keyframe.jpg` | Selected Google Flow tactile keyframe | 2752×1536 | `f303659843b8da2edec9a2fa473b0f59726416182a6a57764fd514b875ee8537` |

The deterministic SVG/PNG pair is the reproducible production source. The
Flow keyframe is the one selected generative still after visual comparison; a
second framed variant was rejected rather than staged. Video candidates that
rotated or scaled the coral square, changed the graphite path, or introduced
new marks were also rejected and are not part of the repository.

Allowed use: an obviously abstract opening or transition sting. Do not present
these assets as IconFlow UI, review evidence, receipt evidence, or generated
icon output. The real proof surfaces remain the exact files bound in
[`../../PROMO_VIDEO.md`](../../PROMO_VIDEO.md).
