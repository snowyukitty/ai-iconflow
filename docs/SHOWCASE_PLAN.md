# Showcase production plan

This plan turns IconFlow's technique catalog into launch evidence. It is a
production queue, not a promise that draft icons are already approved.

Status (2026-08-12): the nine first-wave Theme Worlds are joined by the
[100-case Gallery](GALLERY.md). The public set is selected from 111 generated
directions; every admitted icon passes the same source, native-size, receipt,
and case-record quality gate.

## Two independent axes

- **Technique family = how it is drawn.** A structural grammar such as woven,
  stencil cut, woodcut, or glass stack.
- **Product world + user job = what and why.** Relationships, companions,
  original stories, games, tools, and culture.

The site should say `One pipeline. Many worlds.` Anime and games are product
worlds, not technique families. All anime/story work must be original: never
imitate a named artist, studio, franchise, or living creator's signature style.

## Public-case quality gate

Each icon must follow the full workflow:

1. brief with intent, user job, essence, personality, palette, cliché, signature
   hypothesis, and target set;
2. four or more concept nouns from different lenses;
3. two or three SVG finalists and a rendered silhouette bake-off;
4. clean `check`, static and interactive target review, and all six scores ≥4;
5. source-bound receipt, gated `ship`, and a linted casebook record;
6. 16/32/128 renders, silhouette, target context, and a deterministic 3–5 second
   concept→proof→target video shot.

If any candidate misses a gate, preserve the brief and change the technique or
concept. Never lower the rubric or keep a weak style to satisfy a count.

## Controlled comparison strips

### Catnap, six structural languages

Hold the job, curled-cat noun, tail wedge, and palette constant. Rebuild the
geometry as `mascot`, `clay`, `pixel-grid`, `stained-glass`, `ink-brush`, and
`woodcut`. This demonstrates that a technique changes construction rather than
applying a filter.

### Stencil cut, six worlds

Keep the single-plate/semantic-hole grammar. Apply it to an umbrella, dog tag,
koi, brooch, maze slab, and proof parcel. This demonstrates that a technique is
not tied to the house rail or one subject.

## Production order

1. Build `Keepsake Knot` first because it proves the relationship brief and the
   new woven topology.
2. Build `Co-op Lock` next because it supplies the strongest app-card→linked-tray
   story for the website and video.
3. Build `Catnap Focus`, `Trail Tail`, and `Koi Return` as the approachable animal
   run.
4. Build `Quiet Hero` and `Sky Courier` together as an original-story pair with
   strict no-imitation review.
5. Build `Boss Helm` and `Forest Familiar` as opposite hard-material/organic
   treatments.
6. Only after real cases exist, produce the comparison strips from shared source
   geometry and publish the first→final evidence that actually occurred.
