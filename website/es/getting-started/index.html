El modelo operativo

El agente diseña.
IconFlow lo prueba.

El agente investiga el producto, explora conceptos distintos y crea SVG semántico. IconFlow aporta el manual de diseño, el renderizador determinista, el control de calidad, las transformaciones de destino y el ciclo de aprendizaje. No es un generador de imágenes a partir de prompts.

Windows · PowerShell

git clone https://github.com/snowyukitty/ai-iconflow.git
cd ai-iconflow
python -m venv .venv
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
.\.venv\Scripts\python.exe -m iconflow doctor
.\.venv\Scripts\python.exe -m iconflow ship `
  --config brand\iconflow.toml `

El ciclo completo

Cada comando
se gana su lugar.

Ejecuta estos comandos desde el proyecto que usa IconFlow. Usa Python del entorno virtual de IconFlow mediante su ruta absoluta para que la configuración y las fuentes finales permanezcan con el producto al que pertenecen.

  1. 01
    Brief

    Escribe el contrato del producto.

    Registra la intención antes de dibujar. La configuración también fija destinos, colores, rutas y el comportamiento de la bandeja del sistema.

    python -m iconflow init --out iconflow.toml \
  --name "My App" --essence proof \
  --targets web,tauri,electron,tray
  2. 02
    Explora

    Fuerza ideas visuales distintas.

    Crea al menos cuatro conceptos desde perspectivas distintas. Los preajustes de técnica sirven de andamiaje; nunca son identidades terminadas.

    python -m iconflow styles
python -m iconflow new flat-geometric \
  --out work/my-app/a.svg
  3. 03
    Compara

    Elige la forma antes de pulir.

    Renderiza juntos dos o tres finalistas. Evalúa la lámina a 128px, 16px y en silueta.

    python -m iconflow compare \
  work/my-app/a.svg work/my-app/b.svg \
  work/my-app/c.svg --out work/my-app/bake.png
  4. 04
    Inspecciona

    Revisa transformaciones reales de cada destino.

    Corrige todas las advertencias. Después inspecciona los píxeles nativos, el alfa, los recortes adaptativos, las esquinas de escritorio y los contextos de bandeja del sistema.

    python -m iconflow check master.svg
python -m iconflow review --config iconflow.toml \
  --out work/my-app/review.png \
  --html work/my-app/review.html
  5. 05
    Publica

    Haz que cualquier fallo bloquee la aprobación.

    Exporta el receipt de Review Lab solo cuando cada eje alcance 4/5. Los cambios en la fuente o los destinos dejan obsoleto ese receipt.

    python -m iconflow ship \
  --config iconflow.toml \
  --review master-review.json
  6. 06
    Aprende

    Devuelve lo aprendido al sistema.

    Registra qué falló primero, qué cambió y una regla reutilizable. Un icono sin registro no enseña nada.

    python -m iconflow case new ...
python -m iconflow case lint
python -m iconflow case stats

Familias de salida exactas

Pide solo
las superficies que publicas.

Los destinos son explícitos. IconFlow no promete «todas las plataformas», y una tarjeta de app completa no se convierte sin más en una silueta útil para la barra de menús.

WEB / PWA

Superficies del navegador

favicon en SVG e ICO, Apple touch icon, activos PWA de 192px y 512px, además de un icono enmascarable y un fragmento de manifiesto.

--targets web,pwa
TAURI

Paquete de escritorio

Tamaños PNG, ICO, ICNS y la estructura convencional src-tauri/icons para aplicaciones de escritorio Tauri v2.

--targets tauri
ELECTRON

Entradas para el empaquetador

Activos PNG, ICO e ICNS multiplataforma para los flujos de empaquetado de Electron y electron-builder.

--targets electron
BANDEJA DEL SISTEMA

Marcas para la barra de menús

PNG en color para la bandeja del sistema, activos de plantilla de macOS y una utilidad de TypeScript. Se recomienda especialmente un tray.svg dedicado solo a la marca.

--targets tray

Compilación de ejemplo

Una sola fuente. Ramas explícitas.

El master.svg (archivo maestro) editable sigue siendo la fuente de verdad junto al proyecto. Los archivos generados siempre se pueden reconstruir.

Límites conocidos

Trabajar en local no significa
que sea mágico.

  • Instala desde PyPI.Ejecuta pip install iconflow o uv tool install iconflow. La instalación desde el código fuente sigue disponible para quienes contribuyen.
  • Descarga única.La configuración necesita acceso a la red para las dependencias y Playwright Chromium; después, el renderizado y las compilaciones son locales.
  • Alcance de escritorio.La salida de Tauri cubre actualmente los activos de escritorio, no los conjuntos de inicio e iconos de Android o iOS.
  • Prueba ligada a la cadena de herramientas.La repetibilidad presupone el mismo SVG normalizado, la misma configuración y las mismas versiones de IconFlow, Chromium y Pillow.
