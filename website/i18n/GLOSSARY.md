# IconFlow site translation glossary

The English pages under `website/` are the source of truth. Every other
language is generated by `scripts/build_i18n.py` from a catalog in this folder.
This file is the contract every catalog must follow. A draft that breaks it is
not merged.

Languages: `es` (Español), `ja` (日本語), `zh-Hant` (繁體中文, Taiwan usage),
`zh-Hans` (简体中文, mainland usage).

## 1. The mechanical rules (a build failure, not an opinion)

1. **Every key in `en.json` must appear in your catalog.** The build fails
   closed: one missing key and the whole language is dropped. There is no
   English fallback inside a translated page.
2. **Placeholders are markup, not text.** `<0>…</0>` is a wrapped element and
   `<3/>` is a self-contained one (an image, a line break, or a command such as
   `<code>iconflow check</code>`). Keep every placeholder exactly once, keep
   `<n/>` self-closing, never renumber them, never add new ones. Move them
   where the target grammar needs them.
3. **Braces are runtime values.** `{size}`, `{count}` are filled in by the page
   scripts. Keep them verbatim.
4. **Never translate evidence.** File names (`master.svg`, `review.json`,
   `iconflow.toml`, `docs/LEARNINGS.md`, `AGENTS.md`), commands, hashes, score
   strings such as `4/5/4/5/4/4`, and rubric-axis identifiers inside code stay
   byte-identical.
5. **Numbers stay Arabic numerals** (137, 16px, 100, 20, 6/6).
6. Validate before you hand the draft over:
   `python scripts/build_i18n.py --check-catalog website/i18n/<code>.json`

## 2. The honesty rules (the reason this site exists)

The site never overclaims. Translate the hedge, do not smooth it away:

- **"temporary mark"** — Petal Haypile is explicitly the current, intentionally
  revisable mark. Keep "temporary" in every language.
- **"not published on PyPI yet"** — keep the "yet"; do not imply a release.
- **"passed review" / "gated"** — a local, recorded review with scores, not a
  third-party certification.
- **"clean-room" / "not affiliated with or endorsed by"** — legal wording;
  translate literally, never soften or drop.
- **"Apache-2.0 code · IconFlow identity subject to trademark policy"** — keep
  the two halves distinct.
- No new superlatives, no invented benchmarks, no "the best", "industry
  standard", or "certified".

## 3. Terms that stay in English

Product and interface names, because that is what the visitor types and sees:

`IconFlow`, `Remix Lab`, `Proof Lab`, `Flow Gate`, `Theme Worlds`,
`Getting Started` (as the page name in a link), `Petal Haypile` and every other
mark name (`Koi Heart`, `Leaf Ferry`, `Deep Canopy`, …), `Apache-2.0`,
`GitHub`, `PyPI`, `Python`, `Git`, `PowerShell`, `Chromium`, `macOS`, `SVG`,
`PNG`, `WebP`, `JSON`, `PWA`, `CLI`, `SHA-256`, `favicon`, `16px`, and every
`iconflow …` command (`check`, `review`, `ship`, `init`, `demo`, `case new`).

**`receipt`** stays English as well: it names a concrete JSON artefact. On the
first use on a page, add a short parenthetical gloss in the target language,
then use `receipt` alone afterwards — **one gloss per page, never in a button
label**. Use the same gloss everywhere: `(comprobante)` in es, `（承認記録）`
in ja, `（憑證）` in zh-Hant, `（凭证）` in zh-Hans. Same treatment for
`master.svg`, whose gloss goes in body copy only.

A mark name may take a gloss on first use — `Petal Haypile（花びらの干し草）` —
but the English name must remain and must not be replaced.

## 5. Style per language

**All languages.** Keep the English separators `·`, `—`, and `→` where they are
structural. Keep sentence-case headlines short: the display type is set very
large and a long line breaks the layout. Prefer the imperative for buttons.

**es.** Usted-free, neutral Spanish; address the reader as *tú* implicitly by
using the imperative ("Empieza", "Inspecciona"). Open questions and
exclamations with `¿` `¡`. Avoid regionalisms.

**ja.** です・ます体 for sentences; headlines and labels may be noun phrases.
Full-width punctuation（、。）. Put a half-width space between Japanese text and
Latin words or numerals: `16px の証拠`. Do not use 全角 Latin letters. Avoid
long katakana chains where a plain word works.

**zh-Hant.** Taiwan usage and vocabulary (軟體, 檔案, 介面, 程式, 預設, 網頁).
Full-width punctuation（，。、；：）. Put a half-width space between Chinese and
Latin/numerals: `16px 的校樣`. No 「兒」化, no mainland-only terms.

**zh-Hans.** Mainland usage (软件, 文件, 界面, 程序, 默认, 网页). Same spacing
rule. **Write it from the English, not by converting the Traditional draft** —
the vocabulary differs, not only the characters.

## 6. Length

These strings sit in a fixed layout. Keep within roughly 1.3× the English
character count for buttons, navigation items, labels, and `dt`/`dd` pairs; for
CJK, aim below the English character count. Page `<title>` stays under about 60
characters and `meta description` under about 155.
