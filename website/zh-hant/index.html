IconFlow 是本機 CLI 與代理程式工作流程，能把一張可編輯的 SVG 轉成你選的網頁、PWA、桌面與系統匣素材。自動化檢查會攔截機械性風險；交付會維持封鎖，直到針對該精確原始檔記錄一筆當前的六軸審查。

決策工作流程，不是轉檔器

設計。審查。交付。
然後學習。

產生器給出選項。轉檔器產出檔案。IconFlow 讓設計決策可見、可重複、可稽核。

  1. 01

    設計說明

    記錄使用者任務、本質、配色、陳腔濫調與精確目標。

  2. 02

    探索

    強制產出四個不同概念，並給最強者一個可據為己有的手法。

  3. 03

    比較

    把決選方案做成一張剪影優先的對照表。先選形，再修潤。

  4. 04

    檢視

    審查原生像素、alpha、裁切、深／淺版面與真實目標。

  5. 05

    交付

    僅在自動化 QA 全數通過、且每項人工分數至少 4/5 時才建置。

  6. 06

    學習

    把每一次未通過的審查，寫成下一張圖示可重用的案例集規則。

你的圖示值得
誠實的最後一哩路。

選代理程式協助的路徑，或直接操作 CLI，然後建置已簽入的 IconFlow 品牌圖示家族。五分鐘證明的是引擎，不是新的識別；setup 會下載一次 Chromium，此外沒有任何東西離開你的機器。

PowerShell

git clone https://github.com/snowyukitty/ai-iconflow.git
cd iconflow
python -m venv .venv
.venv\Scripts\python.exe -m pip install .
.venv\Scripts\python.exe -m iconflow setup
.venv\Scripts\python.exe -m iconflow doctor
.venv\Scripts\python.exe -m iconflow ship --config brand\iconflow.toml --review brand\master-review.json
