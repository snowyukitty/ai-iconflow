## Summary
A quiet workspace identity layer needed a favicon that answered which workspace without becoming another developer-tool chevron. A physical identity tag won the silhouette bake-off: its aperture names the object and its single stepped edge carries the nested-path idea at 16 px.

## What failed first
The folder finalist kept its counter at 16 px but its silhouette collapsed into
a generic file-manager glyph. The station placard kept stronger color contrast
but read as a monitor once color was removed. Choosing the identity-tag object
fixed the distinctiveness problem before master review; its 152-unit aperture
and 144-unit edge step both survived as deliberate two-pixel-scale features.

## Lessons
- [x] For workspace-orientation tools, an identity tag can name the user job
  more directly than a folder, location pin, or terminal glyph; budget the tag
  aperture and path notch as independent two-pixel features before drawing.
  This applies the existing user-job, specificity, and pixel-budget rules in
  L2, L20, and L21.
